# AI 记忆（目标版本 v0.2.2）

本轮保留三个开发阶段和独立 PR，统一在功能与必要参数实测完成后发布 v0.2.2。

第一阶段已接入数据库中的完整问答轮次、会话记忆开关与模型调用观测。最近 12 轮是可配置试验默认值；页面的 80 条是读取页大小，与模型上下文无关。历史不由浏览器提交；失败和本地回答不当作模型历史。导入记录只使用相邻且角色有效的完整问答。

模型默认 deepseek-flash，明确使用非思考模式。问答输出 4096、温度 0.4 均为试验配置，尚未通过真实模型比较选定。输入按 UTF-8 字节加消息开销保守估算，API usage 才是实际用量。必要内容超过预算时不会静默截断。

会话开关保存到数据库，关闭不删除聊天。修改开关会使进行中的旧记忆快照失效，迟到答案不保存；记录仍可查看并重试。模型调用位于短事务之外。

后续阶段增加增量摘要、需用户确认的长期记忆，以及累计 10 元、最多 120 次调用的真实参数对照。测试使用虚构资料，报告必须展示实测用量、时间、失败和未测项；不得把模拟测试视为真实模型效果。
