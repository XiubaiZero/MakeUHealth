## 调用与费用

上限 3 元、60 次；实际 **52 次**，按官方高峰价和返回 usage 保守估算 **0.03338080 元**，无未知 usage 预留。价格核对来源：[DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，缓存输入 / 非缓存输入 / 输出每百万 token 为 0.04 / 2 / 8 元。估算不是账号账单。

首次驱动的结果格式处理错误发生在 1 次分类之后，该调用未计入有效分类评分，但保留在账本与总费用中。修复后完成 40 次有效分类和 5 组旧新链路对照；没有清空账本或扩大预算。

## 参数与兼容

分类：温度 0、输出 256 token、超时 10 秒、最近 3 个完整问答轮次、输入 8192 UTF-8 字节保守单位、JSON 严格枚举、不重试。输入预算不是实际 token 数。问答仍为温度 0.4、输出 4096、近期 12 轮；摘要和提取仍为输出 2048、辅助超时 20 秒。旧同步接口新增整轮 55 秒期限；异步主问答单次仍为 60 秒、任务过期仍为 180 秒。
