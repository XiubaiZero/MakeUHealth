# v0.2.4：提示词外置

## 目标与范围

将七类静态文案从 Java 外置到 `back_end/src/main/resources/prompts/`，保留原有措辞、语言分支及拼接结构。采用现有回归测试、资源加载检查和代码审查验收；不增加黄金夹具或 characterization tests。

| 文件 | 内容 |
| --- | --- |
| answer-v1.txt | 主问答 system prompt |
| memory-extraction-v1.txt | 长期记忆提取 system prompt |
| summary-v1.txt | 会话摘要 system prompt |
| english-rewrite-v1.txt | 英文改写 system prompt |
| memory-instructions-v1.txt | 记忆使用规则 |
| memory-facts-label-v1.txt | 已确认长期记忆标签 |
| conversation-summary-label-v1.txt | 历史摘要标签 |

## 加载与拼接

- 使用 ClassPathResource 的输入流、UTF-8 和 try-with-resources，组件初始化时读取并缓存；保留现有构造器和直接构造方式。
- 资源无 BOM，加载器仅移除末尾连续 CR/LF，保留正文内部空白。缺失、空白或 BOM 明确报错，包含资源路径和原因。
- 问答、提取和摘要各含一个 `{{languageInstruction}}`，初始化时检查，原有 Java 语言短句负责替换；不处理用户数据中的占位符。
- 记忆规则的连接空格，以及两个标签的前导 `\n\n`、后缀 `\n` 留在 Java；覆盖预校验、正常生成和摘要省略后的重建位置。
- 保留接口、模型、参数、预算、数据库和前端行为；现有意图提示词与 promptVersion 保持原样。
- 不加入 RAG、Python、registry、热更新或措辞优化；修改资源后需重新打包、重启后端。
